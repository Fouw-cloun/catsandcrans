# Cat Site Dust v0.3 — Unity 6 / URP / PC

Обычные файлы, 14 префабов, 37 слоёв, без demo-сцены.

## Установка
Сохраните копию собственных правок. Перенесите Assets/CatSiteDust из архива в Assets проекта с заменой файлов. Дождитесь импорта. Для проверки используйте свежий экземпляр префаба: старые overrides могут сохранять прежние материалы и цвета.

## Бесконечный просмотр без Play Mode
1. Выберите корень префаба с компонентом DustEffect (в Project или в вашей сцене).
2. Нажмите **Loop Preview — all layers** в Inspector.
3. В Scene View эффект повторяется автоматически. **Frame effect in Scene View** наводит вид на него.
4. **Pause / Resume**, **Playback speed**, **Pause between bursts** управляют просмотром. **Stop** или закрытие окна удаляют временную копию.
5. Для Wheel_Rolling установите **Distance emission (m/s)**, например 2. Это имитация интенсивности выброса при движении: источник остаётся на месте, след вдоль траектории не воспроизводится.

Также окно доступно через Tools > Cat Site Dust > Loop Preview. Можно менять выделение: просмотр продолжается. Бесконечные эффекты работают непрерывно; разовые повторяются после полного цикла. Перезапуск Unity, компиляция или вход в Play Mode останавливает предпросмотр. Сам исходный префаб не превращается в looping-эффект.

Копия использует настройки источника на момент запуска. После правки частиц нажмите Start / Refresh. Изменения общих материалов видны сразу. Для проверки всех декоративных слоёв выставьте Quality = Standard или High. Предпросмотр может перекрываться с ручным предпросмотром оригинальных частиц: остановите стандартный Particle Effect preview Unity.

## Материалы и многослойность
- Контактная пыль темнее и теплее, осколки темнее ядра, висящие завитки чуть светлее и прозрачнее.
- Mesh: дополнительное шумовое затенение, индивидуальный оттенок облачка, мягкий переход цвета к концу жизни. Рабочие DepthOnly/DepthNormals сохранены.
- Billboard: мягкая граница, внутренние пятна плотности, вариация оттенков, вихревое растворение, premultiplied alpha.
- Overall brightness — общая яркость; Per puff shade variation — разнообразие; Late lifetime tint — цвет старения.
- Billboard: Opacity и Soft edge width управляют прозрачностью и мягкостью. Это основные слои для настоящей полупрозрачности.
- Mesh остаётся плотным ядром с исчезновением через размер. Mesh alpha via screen dithering — опциональный режим покрытия; выключен по умолчанию, может давать зерно/мерцание. Enable erosion также оставлен выключенным для сохранения проверенной видимости.
- Дополнительные частицы и новые проходы для украшений не добавлены. На mesh добавлена одна выборка шумовой текстуры; GPU-производительность не измерялась.

## Проверки и ограничения
Проверены синтаксис C#, YAML, ссылки GUID, меши и данные 37 систем. Unity Editor здесь отсутствует: сборка C#, компиляция шейдеров, работа окна и окончательный вид требуют проверки в вашем Unity. Это не результат визуального теста в движке.
Tools > Cat Site Dust > Audit Every Layer проверяет симуляцию и ресурсы, не фактические пиксели.

Предпросмотр использует ParticleSystem.Simulate с restart=false для последовательных шагов:
https://docs.unity3d.com/6000.0/Documentation/ScriptReference/ParticleSystem.Simulate.html

Документы UPDATE_02 и старые VALIDATION описывают предыдущие версии. Этот README — инструкция для v0.3.
