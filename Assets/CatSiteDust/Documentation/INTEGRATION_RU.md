# Интеграция (сохранённые инструкции версии 0.1)

В версии 0.2 demo-сцена не поставляется; используйте свою сцену и Audit Every Layer. Остальной API подключения сохранён.

## Подключение к игре

### Пул разовых эффектов

Перетащить `RuntimeSupport/DustPool_Default.prefab` в сцену или вызвать **Tools > Cat Site Dust > Create Pool In Scene**. Префаб содержит 10 разовых эффектов, по 6 экземпляров каждого; глобальный предел — 40 одновременно активных экземпляров. При заполнении запрос отбрасывается, пул не растёт. `DroppedRequests` позволяет заметить недостаточную ёмкость.

```csharp
using CatSite.Dust;
using UnityEngine;

public class ExampleDustTrigger : MonoBehaviour
{
    public DustPool pool;
    public DustEffect landingPrefab;

    public void Impact(Vector3 point, Vector3 normal)
    {
        // strength меняет количество, scale — общий размер.
        // Возврат null допустим: эффект мог быть отсечён бюджетом/дистанцией.
        pool.Spawn(landingPrefab, point + normal * 0.025f, normal,
                   strength: 1f, scale: 1f);
    }
}
```

Пул сам возвращает завершившиеся экземпляры. Не вызывайте Destroy на полученных объектах. Пул предназначен для bursts; колёса и выхлоп размещайте один раз на технике. Держите масштаб корня пула равным (1,1,1). Если создаёте пул кодом, настройте entries на неактивном GameObject до его первого включения/Awake.

### Лапы, прыжки, приземление

Добавить `DustContactEmitter` на объект, получающий события анимации. Назначить pool, walk/run/takeoff/landLight/landHeavy, leftFoot/rightFoot и при необходимости groundProbe на уровне земли. Ground Mask должен включать землю и исключать самого персонажа.

События анимации: `StepLeft`, `StepRight`, `RunLeft`, `RunRight`, `Takeoff`. Метод `Land(downwardSpeed)` вызвать из контроллера после проверки приземления; передать положительную скорость удара, сохранённую **до** обнуления вертикальной скорости. Проба земли предотвращает пыль в воздухе. Не включайте одновременно второй независимый генератор шагов для того же события.

### Падающие объекты и удары

На Rigidbody-объект добавить `DustImpactEmitter`, назначить pool, smallImpact и heavyImpact. Адаптер использует скорость по нормали контакта, небольшую поправку на массу и cooldown. Surface Mask исключает неподходящие поверхности. Это художественное отображение веса, не физическая модель объёма поднятой пыли.

Для лопатки/молотка вызвать `DustContactEmitter.Hit(point, normal, strength)` либо `pool.Spawn(...)` непосредственно из логики попадания. `Chips` здесь — частицы без физической коллизии; настоящие обломки должны быть отдельной системой.

### Колёса

Разместить `Wheel_Rolling` на отдельном якоре около контакта колеса с землёй, а не на вращающемся меше шины. Добавить `DustContinuousEmitter`, оставить requireGround=true, указать Ground Mask. Ось +Y якоря должна смотреть вверх. Источник использует Rate over Distance, поэтому стоящая машина не оставляет непрерывный след.

Выпущенные частицы симулируются в World space. При телепортации дальше 4 м за кадр адаптер очищает старый след и сбрасывает эмиссию. Для больших скоростей/скачков перемещения подберите порог. При реальном телепорте также можно явно вызвать Stop(true), перенести источник и Play().

### Выхлоп и пар

Разместить Exhaust_Idle или Exhaust_Load на выхлопном якоре, повернув локальную +Y вдоль сопла. Добавить DustContinuousEmitter, установить requireGround=false. `throttle` управляет интенсивностью от 0 до 1; ноль останавливает новые частицы, существующие доживают. Не переключайте префабы Instantiate/Destroy каждый кадр: выберите нужный источник заранее или держите два источника и переключайте их эмиссию.

Cooking_Steam ставится над кастрюлей, +Y вверх. Для такого постоянного источника адаптер необязателен; достаточно DustEffect. Если нужен контроль дистанции и выключение — добавьте адаптер с requireGround=false.
